A few things about how this was done, because they're the reason to trust it. Every result I planned is reported, whatever it showed, using the exact words I committed to in advance. That includes the unexciting "no detectable difference" in finding five. Before I registered, independent reviews of the plan and code caught real problems. The biggest: my first version of the main test was mechanically tied to past savings. It would have looked like a discovery, but it was really just restating something we already knew. Catching that before registration meant I could fix it. After registration, it would have been locked in for good. Anything I checked after seeing the results, like the comparison with Medicare's real 2022 targets, is clearly labeled as an add-on. And the registered analysis code ran exactly as registered. Everything is public, the plan, the code, the list of data files and the results, and the full analysis can be rerun from scratch.
